# Hollow Fill

Complemento de Blender (4.2 a 5.x) para **vaciar piezas con pared fija y rellenarlas** con resina epoxi,
poliuretano o espuma. Todo en modo Objeto y la pieza original no se toca.

- Pared del mismo grosor en toda la pieza; lo más fino que dos paredes se queda macizo.
- Agujero de llenado donde hagas clic (o abajo/arriba automático) y respiradero en la punta del hueco.
- Te dice cuántos ml y gramos de relleno necesitas. Exporta a STL en mm.

Instalar: Editar → Preferencias → Complementos → Instalar desde disco → `hollow_fill-1.0.0.zip`.
Guía completa en `hollow_fill/LEEME.md`.
